# C 소켓 + epoll 온라인 오목

첨부된 epoll 에코 서버와 getaddrinfo 클라이언트를 바탕으로 확장한 터미널 프로그램입니다. 웹사이트와는 별도로 실행합니다. Linux/WSL Ubuntu에서 사용하세요. Windows CMD에서 직접 빌드하는 프로그램은 아닙니다.

## 1. 빌드 (서버/클라이언트 PC 각각)
압축을 풀고 omok_epoll 폴더에서 실행하세요.
```sh
make
```
make 없이도 가능합니다:
```sh
gcc -std=c11 -Wall -Wextra -O2 server.c -o server
gcc -std=c11 -Wall -Wextra -O2 client.c -o client
```
gcc/make가 없다면 Ubuntu에서 `sudo apt update` 후 `sudo apt install build-essential`을 실행하세요.

## 2. 서버 PC
```sh
./server 8080
```
서버는 접속 중인 모든 IPv4 인터페이스에서 TCP 8080을 받습니다. 종료: Ctrl+C.

## 3. 플레이어 두 명 접속
서버 PC에서도 별도 터미널에 클라이언트를 실행해야 합니다.
서버와 같은 WSL 안에서 첫 번째 플레이어를 실행할 때:
```sh
./client 127.0.0.1 8080
```
다른 PC에서 두 번째 플레이어를 실행할 때 (IP는 실제 서버 주소로 변경):
```sh
./client 192.168.0.10 8080
```
IP를 소스 코드에 고정하지 않습니다. 실행 인자로 입력하면 됩니다.
첫 접속자는 흑돌 X, 두 번째는 백돌 O입니다. 세 번째 접속자는 거절됩니다.

## 4. 플레이
`8 8` 입력 후 Enter: 가로 8번, 세로 8번에 착수합니다.
가로·세로 좌표는 모두 1~15입니다. 가로는 왼쪽부터, 세로는 위쪽부터 셉니다.
흑부터 번갈아 두며 같은 색 5개 이상을 연결하면 승리합니다.
33/44/장목 금수 없는 자유룰이고 무르기는 없습니다.
`q` 후 Enter: 접속 종료. 상대방에게 종료를 알립니다.
승부가 끝나면 클라이언트가 자동 종료됩니다. 재대국은 두 사람이 다시 접속하세요.
한 명이 나간 경우 남은 사람도 종료된 후 새 대국을 받을 수 있습니다.
한 서버는 동시에 한 대국(2명)만 지원합니다.

## 5. 서버가 WSL인 경우
WSL의 172.x 주소를 다른 PC에서 바로 사용할 수 있다고 가정하면 안 됩니다.
기존에 설정한 포트 전달과 방화벽 규칙이 있다면 상대방은 Windows PC의 실제 LAN IPv4 주소와 8080 포트로 접속합니다.
접속 실패 시 서버 실행 상태, 실제 IP, 같은 네트워크 여부, Windows→WSL TCP 8080 전달, 방화벽 허용을 확인하세요.
공유기 밖의 다른 인터넷에서 접속하려면 별도 네트워크 설정이 필요합니다. 이 프로그램 자체가 공유기/방화벽을 자동 설정하지 않습니다.

## 구조 및 수정점
- server.c: nonblocking + epoll ET. accept/read는 EAGAIN까지 처리.
- 클라이언트별 입력 버퍼: TCP 메시지가 나뉘거나 합쳐져 와도 줄바꿈으로 구분.
- 출력 버퍼 + EPOLLOUT: 일부만 전송되었을 때 나머지 전송.
- 서버에서 차례, 범위, 빈자리, 승리/무승부 검증.
- client.c: 원본 connect_to_server 유지. poll로 키보드와 서버를 동시에 기다림.
- 종료된 소켓 쓰기로 서버가 죽지 않도록 SIGPIPE 처리.
- 터미널 호환성을 위해 화면은 영어, 돌은 X/O로 표시.

## 검증
`python3 test.py`: 로컬 TCP 18080 포트에서 실행.
2명 접속, 추가 인원 거절, 잘못된 차례/좌표/중복 착수, TCP 분할·병합, 승리, 실제 C 클라이언트 대국, 연결 종료를 검사합니다.
개발 환경에서 컴파일과 테스트를 통과했습니다. 사용자 PC 사이 실제 네트워크 연결은 별도 확인이 필요합니다.
